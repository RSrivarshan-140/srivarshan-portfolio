## ⚡ Key Highlights

### 1. Noir & Crimson Op-Art Aesthetic (saai.pro Architecture)
* **Obsidian Noir & Crimson System**: Deep dark Obsidian base (`#050608`), sharp Crimson Red accents (`#e6193c`), Neon Cyan highlights (`#00f0ff`), and Electric Gold (`#f5ee38`).
* **Architectural Crosshairs (`.op-card`)**: Precise technical corner `+` crosshairs on cards, terminal box, experience panels, and 35mm film frame.
* **Brutalist Systems Typography & Buttons**: JetBrains Mono telemetry index tags (`[01 // SYSTEM ARCHITECTURE]`), condensed high-impact display titles, and crisp hairline buttons that invert to crimson on hover.
* **Ambient Op-Art Lighting**: Radial crimson ambient glow across the header and cards over a fine 32px engineering grid.

### 2. Autonomous Cursor Swarm Rebuild Engine (Multi-Agent Simulation)
* **`swarm/swarm.js` — Multiplayer Cursor Swarm Rebuild Engine (Joel Califa / Dhvanil Patel)**:
  * Full-viewport canvas takeover that scans the live DOM layout into a blueprint.
  * Dispatches named multiplayer cursors (Ada, Linus, Grace, Alan, etc.) with custom tools: crosshair box drawers, pen-tool vector paths, typewriters, alignment snapping rulers, and alt-drag duplicates.
  * Integrated Floating HUD:
    * **Tour**: Auto-scrolls through sections as the swarm constructs them.
    * **Speed**: Toggle build velocity (1×, 2×, etc.).
    * **Sound**: Toggle generative pentatonic synthesis audio on/off.
    * **Go Live**: Instantly fades out the canvas overlay and returns full control to the live DOM.
    * **Replay**: Resets and replays the swarm build from the beginning.
* **`swarm-init.js` — Swarm Takeover Bootloader**:
  * Manages the lifecycle of the swarm rebuild, detects font rendering readiness, tab visibility, and triggers smooth Tour mode on page load.
  * Press `Esc` anytime to instantly drop the takeover and reveal the interactive site.

### 3. Atmospheric Ambient Canvas & Interactive Modules
* **`app.js` — Orbital Physics Canvas (`#aurora-canvas`)**:
  * Smooth mouse-parallax orbital physics with deep crimson ambient gradients and concentric expanding radar rings.
  * **GPU Optimization**: Uses `IntersectionObserver` to automatically pause canvas rendering when offscreen or in background tabs.
  * **1-Click Email Copy & Toast Notification**: Automatically copies contact email with a bottom floating toast notification (`#toast`).

### 4. Interactive UNIX Terminal & Architecture Blueprint Modal
* **Interactive UNIX Terminal (Stack 08)**: Live shell prompt supporting commands:
  * `help` — List all available commands
  * `bio` — View Srivarshan's AI engineering profile and background
  * `skills` — List technical stack and neural frameworks
  * `projects` — Deep dive into `reseach-analyzer` and active builds
  * `internship` — Inspect Core2Cloud Technologies AI Engineering program
  * `rag` — Inspect the Hybrid Dense-Sparse RAG architecture formula
  * `contact` — Display email and GitHub connections
  * `matrix` — Toggle neon high-contrast terminal theme
  * `whoami` — Session privileges
  * `quote` — Engineering directive
  * `rebuild` — Trigger multiplayer swarm rebuild tour
  * `clear` — Clear terminal buffer
* **AI Research Assistant Blueprint Modal**: Interactive architecture drawer detailing document ingestion, Hybrid Dense-Sparse Fusion (Dense ChromaDB + Sparse BM25), Citation Router, and NLI Hallucination Evaluation Suite.
